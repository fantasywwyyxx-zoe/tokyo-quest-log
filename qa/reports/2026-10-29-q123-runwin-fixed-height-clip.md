# Q-123 DASH RUN 游戏窗固定 720px 高：矮屏上撞毁按钮整排沉到屏外（S1）

**证据（双路）**：
- Zoe 实机（2026-10-29 11:32）：撞毁结算面，クラッシュ横幅下方的「↻ もう一度 / やめる」被屏幕底部切掉一半，原话「底下看不到了」。
- QA 实验室（cdp-r13，构建 5f3c5bd）：`.run-win` 高度**恒定 720px**、overflow visible、无内部滚动。
  - 390×600：窗体 y27–747（溢出视口 147px）；两按钮 y628–679，**整体在 600 视口之下 79px——完全看不见、点不到**；
  - 390×844：按钮 y637–689，完整可见（余量 155px）。
  - 临界：视口高 < 约 757px 即开始丢按钮。Zoe 的 webview 有效高度正在此区间。

## 影响
撞毁是小游戏每局必经状态，主操作（再来一局/退出）在矮屏上不可达；仅右上 ✕ 可用（不是硬困死，但核心循环被切断）。定 S1。

## 修复方向
游戏窗改视口相对约束：max-height ≤ 可用高度（100dvh 减边距），内部纵向滚动或整体等比收窄；画布高度可弹性，HUD/结算区永远在窗内。

## QA 复测口径
390×600 / 667 / 736 / 844 四档，逐档：起跑→撞毁→结算面全元素（距离读数、进度条、横幅、双按钮）均在视口内且可点；运行中 HUD 同查。
