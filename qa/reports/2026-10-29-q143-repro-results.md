# Q-143 復現結果（live ブラウザ、再訪ゲスト Marlo、2026-10-29 15:53–16:29）

## 確定した構造的な問題（Zoe の「言語設定が曖昧」と一致）
- 言語変更は表示設定パネル内の**循環トグルボタン**のみ。ボタンは「現在の言語」ではなく「**次に切り替わる言語**」を表示する（JA UI で「中文」→ZH UI で「ENGLISH」→EN UI で「日本語」）。
- 「言語／语言」というラベルも、現在値のハイライトも**無い**。現在の言語は周囲の UI から推測するしかない——初見の利用者が「選んだつもり」で逆を掴む構造。
- 入口は設定パネルに一元化（タイトル上部／底栏の表示設定／一覧カード右上の設定ボタン＝同一パネル）。地図・主人公・毎日には独立切替なし。

## 再現できなかった部分
- 再訪ゲスト＋通常ブラウザでは：切替は全画面に即時反映、リロード後も維持、一覧/主人公/毎日で反転なし。
- **未検証の脚**：①真の初回フロー（当該プロファイルに既存ゲスト档があり未走）②微信 WebView（保存領域の持続性が通常ブラウザと異なる可能性）。
- Fay の症状（初回で中文を選択→一覧で英/日）はこの2脚のどちらかで発生している公算。検査への具体的疑い：初回フロー側に別の言語書き込みがあるか／セーブ適用（雲・本地）が jsonb の lang で設定を踏み潰すか。

## データ側の残留（参考）
分類チップ（Art/Fashion/Film…）や料金注記（Free／Varies by program 等）は ZH でも英語のまま——UI ではなくデータ表記。クエスト名の不翻訳とは別に、チップ類を UI 言語に追随させるかは設計判断として開発部へ。
