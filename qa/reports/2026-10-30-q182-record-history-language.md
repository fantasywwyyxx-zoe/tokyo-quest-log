# Q-182 每日記録の履歴が完了時の言語で表示される（S2、実機）

- 発見：2026-10-30 00:33、Zoe 実機（UI＝中文）。每日記録カレンダーで 2026年10月29日 を開くと、見出し・ラベル類は中文（当天的每日完成／连续记录／本月全完成）なのに、**完了した每日任务の名前だけが日本語のまま**：窓側の席で人間観察／雑誌か小さな本を買う／今日の地図を落書きする／LEGENDルートを下見する。
- 切り分け：当日のデイリーページでは同種の任务名が中文で表示される（00:30 実機で確認済み）ため、任务名の多言語テーブル自体は存在する。履歴側は完了時点の表示文字列をそのまま保存・再生しているとみられ、現在の UI 言語に従わない。10/29 は彼女が日文 UI でプレイした日であり、その言語が凍結されている形。
- 対処の方向：履歴には任务の ID／キーを保存し、表示時に現在の言語テーブルから名前を引く（デイリー任务はテンプレート生成なのでキーが存在するはず）。
- 検収：日文 UI で完了した日の記録を、中文／英文 UI で開いても任务名がその言語で表示されること。当日のデイリーページの表示は不変。
